# Resource profiling runner

Reserved location for reproducible model complexity and resource profiling using `src/efdt/resource.py`.

Separate analytical estimates from measured host/device timings. For measured results, report hardware, software, batch size, warm-up, repetitions, timing method and power measurement method. The 13.10 ms and 6.55 mJ manuscript scenario values use assumed 100 MMAC/s and 0.5 W; they are not physical measurements.
