# Explainability experiment runner

Reserved location for selected-record or cohort-level explanation execution using `src/efdt/explainability.py`.

Record the model checkpoint, ECG row/pseudonymous ID, target class, attribution method, baseline, integration steps, perturbation protocol and stability protocol. Deposit attribution outputs and quantitative validation only after the corresponding experiments are run. A working explanation command alone is not evidence of cohort-level or clinical validation.
