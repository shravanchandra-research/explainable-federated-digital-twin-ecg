# Data

The PTB-XL dataset is not included in this repository.

Download PTB-XL version 1.0.3 from https://physionet.org/content/ptb-xl/1.0.3/ and follow its access and citation requirements. Keep the downloaded data outside version control unless there is a documented, permitted reason to include a specific derived artifact.

Do not commit patient-identifiable information, credentials, or private data.
