# Figures

This directory is reserved for reviewed, publication-ready research figures.

Do not add raw ECG traces or patient-level outputs unless the data-use terms, de-identification status, and provenance have been reviewed. Each figure should have a descriptive filename, source script, dataset/split, and a caption explaining whether values are measured, simulated, or scenario-derived.

The framework diagrams and summary plots are currently retained in the project workspace; they have not been included in this code deposit yet.
