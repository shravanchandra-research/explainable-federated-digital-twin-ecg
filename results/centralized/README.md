# Centralized baseline evidence

Reserved for the original centralized CNN run artifacts supporting the manuscript.

Deposit, when available:
- run configuration and random seed;
- training/validation log and early-stopping record;
- checkpoint identifier and SHA-256 hash;
- held-out test predictions and labels;
- class-wise precision/recall/F1/AUROC and macro metrics;
- software environment and Git commit.

The manuscript reports Macro-F1 0.901240 and Macro-AUROC 0.991450. Those values are not currently represented by a centralized metrics file in this repository. Preserve the original evidence; do not create a synthetic log or hard-code the manuscript values.
