# Results and provenance

This folder contains curated result artifacts supplied with the research work.

## Federated learning

- `federated/FedAvg/metrics_IID.json`
- `federated/FedAvg/metrics_non-IID.json`
- `federated/FedAdam/metrics_IID.json`
- `federated/FedAdam/metrics_non-IID.json`

Each JSON preserves the per-client F1 values and summary fields from the supplied source artifact. They have not been regenerated by this repository because the corresponding training implementation and complete run configurations were not supplied.

## Validation reports

`validation_logs/` contains supplied text reports for Experiments 1A–3C. They are historical experiment outputs, not independently rerun proof.

## Figures

The consolidated archive supplied with the project includes a federated optimizer comparison plot and a patient-adaptation F1-delta plot. The current code deposit does not include these image files or their raw plotting data; the source archive is retained in the working research materials. A future deposit should include publication-quality figures with the generating script and full provenance.

## Data hygiene

Do not commit raw PTB-XL waveform data, unnecessary patient-level metadata, private data, secrets, or credentials. New result artifacts should include experiment IDs, configuration, dataset version, split, random seeds, metric definitions, and the source code that generated them.
