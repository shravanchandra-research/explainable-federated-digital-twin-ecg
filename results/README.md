# Results and provenance

This folder contains curated result artifacts supplied with the research work.

## Federated learning

- `federated/FedAvg/metrics_IID.json`
- `federated/FedAvg/metrics_non-IID.json`
- `federated/FedAdam/metrics_IID.json`
- `federated/FedAdam/metrics_non-IID.json`

Each JSON retains the per-client F1 values and summary fields from the supplied source artifact. They have not been regenerated by the current repository because the corresponding training implementation and complete run configurations were not supplied.

## Validation reports

`validation_logs/` contains user-supplied text reports for Experiments 1A and 2A–3C. These reports are retained as historical experiment outputs, not independently rerun proof.

## Patient adaptation and plots

The consolidated archive also contains a patient-adaptation F1-delta plot and a federated optimizer comparison plot. They are source figures, not raw prediction-level data; figures alone are insufficient to recalculate statistics. Do not claim the full adaptation or training pipelines are reproducible until the underlying scripts and prediction-level artifacts are added.

## Data hygiene

Do not commit raw PTB-XL waveform data, unnecessary patient-level metadata, private data, secrets, or credentials. New result artifacts should include experiment IDs, configuration, dataset version, split, random seeds, metric definitions, and the source code that generated them.
